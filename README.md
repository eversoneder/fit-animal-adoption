# fit-animal-adoption

Project for the SD-TA-012 assignment.

A local animal charity currently handles adoptions on paper, with forms going back and forth by email, phone and post. The plan is to build a simple website that lets people view the animals and apply for adoption online instead.

## Plan (rough)
Page listing the animals available for adoption
Online version of the charity's adoption form
Accounts for adopters and for staff
Somewhere for staff to add animals and go through applications

Still working through the requirements, so this will probably change.

## Tech (so far)

Going to keep it simple:

HTML, CSS and plain JavaScript
Firebase for login, database and hosting

## Status

Just getting started, nothing to run yet.
